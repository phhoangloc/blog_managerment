# home project
- Save under the `/home` folder.
- Connect to the backend project (default http://localhost:4000) using variables from the .env file.
- Decode `https://claude.ai/design/p/2747df7c-2a7b-4d03-9e5b-3e8ac9220a13` and use its layout.

## TECH STACK
- NEXTJS
- TYPESCRIPT
- TAILWIND
## Route
### home(`/`)
- view all blog
### about(`/about`)
- view about page
### blog detail(`/blog/slug`)
- view blog detail
